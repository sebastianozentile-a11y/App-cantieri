# CantieriApp - progetto pronto per build

Questo archivio contiene la prima versione del progetto Android.

## Build
In un ambiente con JDK 17+ e Gradle Wrapper:
- Linux/macOS: `./gradlew assembleDebug`
- Windows: `gradlew.bat assembleDebug`

APK generato:
`app/build/outputs/apk/debug/app-debug.apk`

Nota: il Gradle Wrapper scarica automaticamente Gradle 8.9 al primo avvio.
